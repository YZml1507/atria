# Atria — AI 沙盒涌现观察站

25 个智能体在小镇里自由生活。**这是一个两条件对照实验**：同样的 25 人、同样的引擎、同样的种子，唯一变量是**初始世界里有没有"故事"**。

## 两个条件

| | v2（有锚点） | v3（零注入） |
|---|---|---|
| 初始记忆 | 10 人被注入剧情锚点（错领事件 + 三枚信息碎片） | 25 人全部只有日常生活 |
| 天数 | 14 | 35 |
| 事件 | 1,109 | 2,747 |
| 结果 | 全员 25/25 知情；三枚碎片命运完全不同（164/30/0） | 只有一个自发传闻，触达 4/25 人，35 天内容空转 |

## 实验回答的问题

**v2 回答：给定三枚确定性不同的信息，传播链会区别对待吗？**
会。具体的（扳指）被 164 人记住，半具体的（方向）30 人，"好像是灰色"那种措辞不确定的 **0 次**。最硬的证据是周老师本人——她被注入的就是颜色碎片，但 14 天 35 次发言 0 次提颜色，全部追随具体线索：**她自己就是淘汰机制的运行过程。**

**v3 回答：如果什么都不注入，信息会自己长出来吗？**
会，但长不大。吕婶（零注入人设）D1 即兴虚构出"镇上新来了一户人家"——这个设定不存在于任何设定文件中。35 天里它被提及 167 次、触达 4 人，但**从未产生实质内容**：所有台词都是提问（"你听说没？""到底何时到？"），从 D9 起只剩两人在重复互问直到实验结束。

**合并结论：锚点的作用不只是"提供信息"，它把提问式传闻变成陈述式传播。** 没有锚点时，LLM 小镇的好奇心真实存在（天天有人主动问"有啥新鲜事"），但传闻永远停留在提问形态——"看起来在聊"不等于"有信息在传"。

## 诚实声明

- 本实验**不是零干预**。v2 的初始记忆锚点为作者设定；v3 删除了全部锚点，是"零信息注入"而非"零人设注入"（25 人的姓名/职业/性格仍是手写的）
- v2 的三碎片结论仅在有锚点条件下成立；v3 未形成对照，故"确定性决定存活"目前只在有锚点框架内有证据
- 运行期间无任何人工干预：所有对话、决策、记忆增长均由智能体自治产生；429 退避、事件调度由引擎自动处理
- 两轮均为单次运行，无 run-to-run 方差基线

## 仓库结构

```
atria_engine.py      涌现引擎（记忆/决策/社交，含 checkpoint 保护）
atria_world.py       小镇世界（40×30 地图，32 地点）
atria_personas.py    25 位居民人设生成
atria_verify.py      数据一致性校验（所有文档数字可溯源）
atria_fragments.py   三碎片传播口径锁定（程序化判定规则）
atria_video_v4.py    pygame 视频渲染管线（字幕+旁白音轨同步）
atria_figures.py     4 张证据图生成
run_v2/              v2 主交付数据（14 天事件 + 逐日记忆 + 日志）
docs/                设计方案与实验文档
docs/figures/        证据图
renders/             视频
docs/research/       调研归档（15 份，Smallville/AI Town/AgentSociety 精读）
```

## 复现

```bash
python3 atri­a_engine.py 14 --seed 20261014 --outdir run_v2
python3 atri­a_verify.py /home/ubuntu/atria_rerun   # 校验文档与数据一致
```

**注意**：远程 LLM 端点同种子也不逐位确定（两轮运行 D1 事件 79 vs 78）。复现的是**秩序**（颜色碎片 0 传播、扳指最广、反派弧线），不是数字。

## 卖点

**512K 全量记忆** vs RAG top-30 检索：P1v5 实验中，全量记忆在 138,454 token 下判据完整性 3/3，RAG 仅 1/3——**分辨时间线与来源可信度**，只有记忆完整的智能体做得到。[详案 → `docs/atria_plan_v1.1.md`]
