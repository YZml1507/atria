# 方法学（Methodology）

本文档定义实验设计、变量、测量口径与数据索引，供复核与引用。所有结论数字可由 `atria_verify.py` 复算。

## 1. 实验问题

一个信息要传遍 25 个 LLM 居民，需要的是"记忆锚点"（初始信息注入），还是仅仅一句"如果你记得就告诉他"的引导语？

## 2. 设计：2×2 对照

| 变量 | 水平 |
|---|---|
| A. 记忆锚点 | 有（10 人 currently 字段含包裹错领内容：失主/错领者/3 目击者/经手人持事件碎片 + 4 人已听说）/ 零（25 人仅日常人设） |
| B. 社交引导句 | 有（`converse()` prompt 含"如果你清楚记得邮局包裹被错领的事，就告诉他"）/ 无（`--neutral-social`） |

控制：同引擎版本、同 25 个人设、同作息与地图；每格条件用不同随机种子复现（见矩阵）。运行期零人工干预。

## 4. 测量口径

- **知情判定**：某居民某日记忆中首次出现传闻标志词（有锚点 run：`错领/包裹/扳指/旧物/纸箱/邮局`；hint0g：`银元/山道/坛子/挖`；v3/v3s2：`远客/新来的/新来/南边来/本县人/外乡/那户人家/生面孔`；v3s3：`婚事/聘/亲事/嫁/迎亲/媒`；v3s4：`磨坊/磨盘/埋/刨开/邪乎`（磨坊故事族）；v3s5：`失踪/没影/下落/进山/音信`（石匠失踪族）），由 `atria_fragments.py` / `hall/export_data.py` 程序化判定，非人工标注。判定用记忆 checkpoint 而非 `say` 字段：引导句会污染台词（如张石匠照句反问"银元可是真的？"但从未获得内容）。
- **碎片转述**：三碎片（扳指/方向/颜色）各自口径锁定，排除持有者自记；方向为双条件转述。见 `atria_fragments.py`。
- **注入报警**：零锚点 run 中任何"包裹/错领"类词出现于社交文本即报警（v3 全程 0 次）。
- **事件流**：`dayNN.jsonl` 每行一条事件（say/move/think/plan），`mem_dayNN.json` 为当日终记忆快照。

## 5. 结果摘要

| | B=有引导 | B=无引导 |
|---|---|---|
| **A=有锚点** | 23–25/25（v2 ×5，4/5 饱和 @D8–14） | 24–25/25（v4np ×5，4/5 饱和 @D8–11） |
| **A=零锚点** | 23–25/25（hint0 ×5，全部内容为编造）；银元泛化 24/25 | 4–25/25 @D35（v3 五种子里程：4/19/9/25/24，双峰分布） |

- 引导句对**广度**（饱和速度）无显著影响（D8/D9 vs D9/D14），对**深度**（碎片转述量）放大 ~4×（164/30/0 → 44/8/0）
- 零锚点+有引导下，居民编造内容收敛于引导句措辞（"错领""包裹"），并出现跨居民转引的虚构归因句（"哪是错领，分明是手长"）；换银元传闻仍编造出完整故事
- 双传闻并行（multi）：有锚包裹 25/25 @D10，零锚银元仅 2/25，编造传闻在有锚对手面前几乎绝迹
- 辟谣干预（debunk）：第 7 天饱和后注入公告，提及人数约减半（公告前 11–19 → 7–10/天）但无一人忘记：公告抑制表达，不擦除记忆
- 三碎片确定性排序在有无引导下一致：具体 > 半具体 > 不确定（0 转述）

## 6. 局限

- 2×2 各格 n=5，v3 零注入 n=5（35 天/轮）；multi/debunk 各 n=3、hint0g n=1，边界条件结论按一致性趋势陈述
- 远程 LLM 端点同种子不逐位确定；复现的是趋势
- 人设为手写；"零注入"指零信息注入，非零人设注入
- 知情判定依赖标志词命中，对隐喻式转述可能漏报（下偏）
- debunk 公告在第 7 天注入（恰为饱和日），测的是饱和后辟谣；multi 两传闻锚点不对称，回答的是"有锚 vs 零锚竞争"
