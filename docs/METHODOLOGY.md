# 方法学（Methodology）

本文档定义实验设计、变量、测量口径与数据索引，供复核与引用。所有结论数字可由 `atria_verify.py` 复算。

## 1. 实验问题

一个信息要传遍 25 个 LLM 居民，需要的是"记忆锚点"（初始信息注入），还是仅仅一句"如果你记得就告诉他"的引导语？

## 2. 设计：2×2 对照

| 变量 | 水平 |
|---|---|
| A. 记忆锚点 | 有（6 人持有"包裹错领"事件碎片）/ 零（25 人仅日常人设） |
| B. 社交引导句 | 有（`converse()` prompt 含"如果你清楚记得邮局包裹被错领的事，就告诉他"）/ 无（`--neutral-social`） |

控制：同引擎版本、同随机种子（20261014）、同 25 个人设、同作息与地图。运行期零人工干预。

## 4. 测量口径

- **知情判定**：某居民某日记性中首次出现传闻标志词（有锚点 run：`错领/包裹/扳指/旧物/纸箱/邮局`；v3：`远客/新来的/外乡/生面孔` 等），由 `atria_fragments.py` / `hall/export_data.py` 程序化判定，非人工标注。
- **碎片转述**：三碎片（扳指/方向/颜色）各自口径锁定，排除持有者自记；方向为双条件转述。见 `atria_fragments.py`。
- **注入报警**：零锚点 run 中任何"包裹/错领"类词出现于社交文本即报警（v3 全程 0 次）。
- **事件流**：`dayNN.jsonl` 每行一条事件（say/move/think/plan），`mem_dayNN.json` 为当日终记忆快照。

## 5. 结果摘要

| | B=有引导 | B=无引导 |
|---|---|---|
| **A=有锚点** | 25/25 @D9（v2） | 25/25 @D8/D9（np/np2, n=2） |
| **A=零锚点** | 25/25 @D8（hint0，全部内容为编造） | 4/25 @D35（v3） |

- 引导句对**广度**（饱和速度）无显著影响（D8/D9 vs D9），对**深度**（碎片转述量）放大 ~4×（164/30/0 → 44/8/0）
- 零锚点+有引导下，居民编造内容收敛于引导句措辞（"错领""包裹"），并出现跨居民转引的虚构归因句（"哪是错领，分明是手长"）
- 三碎片确定性排序在有无引导下一致：具体 > 半具体 > 不确定（0 转述）

## 6. 局限

- 每格 n=1–2，无 hint 格有双种子复现，其余单次；方差基线有限
- 远程 LLM 端点同种子不逐位确定；复现的是趋势
- 人设为手写；"零注入"指零信息注入，非零人设注入
- 知情判定依赖标志词命中，对隐喻式转述可能漏报（下偏）
