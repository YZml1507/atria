# 安镇 LLM 小镇信息传播实验报告

> 十二轮 run / 231 模拟日 / ~16,000 条 LLM 生成事件 / 25 位手写人设居民
> 数据：各 `run_*/` 目录全量入库（事件流 + 逐日记忆 checkpoint）
> 口径与数字均可由 `atria_verify.py` 复核

## 摘要

在 25 个 LLM 居民构成的受控小镇中，我们做了一组"记忆锚点 × 引导句"的 2×2 对照实验（每格多种子复现，n≥2），外加四类扩展实验（零注入多种子、刺激泛化、双传闻竞争、辟谣干预）。主要结论：**传闻可以完全不依赖事实被"引导句"播种并传遍全镇；但当镇里存在一条有锚传闻时，编造传闻几乎无法挤入传播链；而对已饱和的传闻，公告辟谣只能压低其活跃度、不能将其清除。**

## 1. 研究问题

| 编号 | 问题 | 对应实验 |
|---|---|---|
| RQ1 | 有锚信息在社交小镇中如何传播？传播质量受什么决定？ | v2 / v2s2 / v4np / v4np2 |
| RQ2 | 零注入条件下，信息会自发产生并传遍全镇吗？ | v3 / v3s2 / v3s3 |
| RQ3 | "引导句"（如果你记得就告诉他）对传播的作用是什么？ | 2×2 对照 + hint0 / hint0s2 |
| RQ4 | 编造出的传闻是否依赖特定刺激内容？ | hint0g（银元泛化） |
| RQ5 | 多条传闻并行、或事后辟谣，分别会怎样？ | multi / debunk |

## 2. 实验设计

### 2.1 因素

| 因素 | 取值 |
|---|---|
| 记忆锚点 | ON：10 位居民的 `currently` 字段含"邮局包裹错领"相关内容（失主/错领者/3 名目击者/经手人持事件碎片，另 4 人已听说）；OFF：人设中无任何包裹信息 |
| 引导句 | ON：每日社交 prompt 含"如果你清楚记得镇上那件'邮局包裹被错领'的事，就把它告诉对方"；OFF：中性社交 prompt |
| 传闻客体 | 包裹错领（默认）；银元（hint0g/multi 换刺激验证泛化） |
| 干预 | 无（默认）；第 7 天全镇注入辟谣公告（debunk） |

### 2.3 指标口径

- **知情（informed）**：某居民逐日记忆 checkpoint 中首次出现传闻标志词的日期。刻意不用事件 `say` 字段：引导句会污染台词（hint0g 中张石匠能照句反问"银元可是真的？"，但其记忆从未获得内容），记忆 checkpoint 才是可靠口径。
- **转述边（edge）**：从对话记忆 `"X 告诉我/回我说: …"` 提取的 src→dst 传播边；`first=1` 表示该边当日恰为 dst 的知情日（疑似首传）。
- **提及人数**：当日事件中 `say` 命中传闻标志词的独立居民数（活跃度口径，非知情口径）。

## 3. 结果

### RQ1 有锚信息的传播：全员饱和，碎片存活由措辞确定性决定

四个有锚种子全部 14 天内 25/25 饱和（D8/D9/D9/D14）。三位目击者碎片的转述量随措辞确定性单调下降（v2 / v4np 对照）：

| 碎片 | 措辞确定性 | 有引导 | 无引导 |
|---|---|---|---|
| 扳指 | "手上戴着个旧扳指"（具体） | 164 | 44 |
| 方向 | "抱着纸箱往镇东头走"（半具体） | 30 | 8 |
| 颜色 | "衣裳颜色偏浅，好像是灰色"（不确定） | 0 | 0 |

措辞不确定的碎片被传播链**静默丢弃**：颜色碎片 14 天 0 次转述，且持有者周老师本人 35 次发言零次提及。该结论在有无引导下一致，不受引导句混杂。

### RQ2 零注入：会自发产生信息，但长不大

三个种子各自即兴虚构出不同传闻（s1/s2"镇中新来一户人家"，s3"周家丫头出嫁"婚事），触达 4 / 19 / 9 人，35 天均未饱和。所有台词为提问形态（"你听说没？"），无实质内容增殖；s1 从 D9 起退化为两人重复互问。**自发好奇心真实存在，但缺乏锚点的内容无法完成全镇传播。**

### RQ3 引导句：传播非必要条件，但能在零锚下"播种"

- **广度**：关掉引导句，有锚传闻照样 25/25 饱和（v4np D8 / v4np2 D9，与 v2 相当甚至更快）
- **深度**：碎片转述量降至约 1/4（164→44）：引导是扩音器，不是发动机
- **播种**：零锚点 + 引导句时，包裹从未存在，全镇却集体编造并传遍完整包裹案（25/25，两种子复现），内容收敛于引导措辞并自发增殖归因句（"哪是错领，分明是手长"被多人转引）和追查行为（查底单、对签收、惊动巡检司）

**传闻不靠事实传播，靠问题传播。** 这也意味着 v2 的 25/25 中相当部分应归因于逐日 prompt 提示，而非纯粹涌现。

### RQ4 刺激泛化：编造不依赖特定内容

把传闻客体换成"镇外山道挖出一坛银元"重跑同格条件：24/25 知情、72 条转述边（其中首传边 24），全镇照样编造出完整故事。唯一未达标的张石匠只有"都传遍了，就你闷在石场里"这类元指涉记忆：听见了传闻的存在，从未被告知内容（该案例也是"知情必须用记忆口径"的直接证据）。

### RQ5 竞争与干预：两条边界条件

**双传闻并行（multi）**：引导句同时提包裹（有锚）与银元（零锚）。结果包裹 25/25 @D10、银元仅 2/25：单跑能传遍全镇的编造传闻，在有锚对手面前几乎绝迹。**集体编造需要一个空的信息生态位。**

**辟谣干预（debunk）**：第 7 天（包裹恰在当天 25/25 饱和）注入全镇公告"同名误传、包裹已签字取回"。公告后当日提及人数从公告前爬升段的 11–19/天降至 7–10/天（对照组同段维持 12–21/天），但无一人"忘记"：公告抑制表达，不能擦除记忆。**对已饱和的信息系统，事后干预的窗口已经关闭。**

## 4. 效度威胁

- **不是零干预**：有锚条件的初始碎片为作者设定；"零注入"指零信息注入，非零人设注入
- **样本量**：2×2 各格 n=2，v3 n=3，multi/debunk 各 n=1，后两条结论目前为单次观察
- **端点不确定性**：远程 LLM 同种子不逐位确定，复现的是趋势不是数字
- **知情口径**：依赖标志词命中，对隐喻式转述可能漏报（下偏）；say 字段受 prompt 污染不可用
- **干预设计**：debunk 公告在第 7 天才注入（恰为饱和日），测的是"饱和后辟谣"，未测饱和前辟谣
- **双传闻设计**：multi 中两传闻锚点不对称（包裹有锚、银元零锚），结论回答的是"有锚 vs 零锚竞争"，不是一般性的传闻竞争
