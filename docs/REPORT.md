# 安镇 LLM 小镇信息传播实验报告

> 二十七轮 run / 483 模拟日 / ~38,000 条 LLM 生成事件 / 25 位手写人设居民
> 数据：各 `run_*/` 目录全量入库（事件流 + 逐日记忆 checkpoint）
> 口径与数字均可由 `atria_verify.py` 复核；展厅数据由 `hall/export_data.py` 从原始事件流重新生成

## 摘要

在 25 个 LLM 居民构成的受控小镇中，我们做了一组"记忆锚点 × 引导句"的 2×2 对照实验（每格 n=5 独立种子），外加三类边界实验（刺激泛化 n=1、双传闻竞争 n=3、辟谣干预 n=3）。主要结论：**有锚或仅有引导句的传闻均能可靠传遍全镇（所有注入格 run ≥23/25，近饱和率 15/15）；零注入镇子也会自发编造传闻且偶有饱和，但结果离散不可控（4–25/25）；编造传闻只能在空的信息生态位中扩散（有锚竞争者下 2–9/25）；对已饱和的传闻，公告辟谣只能压低其活跃度、不能将其清除。** 注入格 vs 零注入格的"传遍全镇"（≥23/25）率差异具统计显著性：15/15 vs 2/5（双侧 Fisher 精确检验 p≈0.009）。

## 1. 引言

生成式智能体研究已证明 LLM 居民能在沙盒镇子里涌现出可信的社交行为（Generative Agents 的派对邀请自发扩散是标志性例子），但"一条信息在这样的社会里如何传播、传播成败由什么决定"一直缺乏受控证据：演示型工作展示现象却不操纵变量，而经典信息扩散建模（流行病式 SIR/传闻模型）有传播动力学却没有内容语义，无法回答"传闻的内容在传播中会怎样变形、什么内容能活下来"。

本实验把小镇当成一台可操纵的仪器：固定引擎、人设、地图与作息，只动信息注入相关的变量，共跑 27 轮、483 个模拟日、约 3.8 万条事件，全部入库可复核。

**研究问题：**

| 编号 | 问题 | 对应实验 |
|---|---|---|
| RQ1 | 有锚信息在社交小镇中如何传播？传播质量受什么决定？ | v2 ×5 / v4np ×5 |
| RQ2 | 零注入条件下，信息会自发产生并传遍全镇吗？ | v3 ×5（35 天/轮） |
| RQ3 | "引导句"（如果你记得就告诉他）对传播的作用是什么？ | 2×2 对照 + hint0 ×5 |
| RQ4 | 编造出的传闻是否依赖特定刺激内容？ | hint0g（银元泛化） |
| RQ5 | 多条传闻并行、或事后辟谣，分别会怎样？ | multi ×3 / debunk ×3 |

## 2. 相关工作与定位

- **生成式智能体**：Generative Agents（Park et al., 2023）证明了记忆—反思—规划架构下的可信个体与涌现行为；AgentSims 等后续工作提供沙盒评测设施。这条线测的是"行为像不像人"，没有以受控方式操纵信息变量。
- **传闻/信息扩散建模**：Daley–Kendall 传闻模型与 SIR/SEIR 一族给出"易感—感染—康复"式的传播动力学，但智能体被抽象为无内容的状态节点，不能观测措辞存活、虚构归因这类语义级现象。
- **本工作的增量**：用 LLM 智能体镇子同时获得两层可观测量——宏观扩散动力学（S 形饱和曲线）与微观内容演变（碎片措辞、误传、编造）；并以 2×2 因子设计 + 每格多随机种子复现，把"涌现现象"升级为"受控结论"。

## 3. 实验装置与设置

### 3.1 模拟系统

引擎为自研 `atria_engine.py`（约 350 行，全量开源），世界为 40×30 网格小镇，含 12 个命名地点（邮局、杂货铺、诊所、赵宅、镇学校、镇公园、老磨坊酒吧等）及街道，连通性经脚本校验。核心机制：

- **时间**：每模拟日 48 步（30 秒/步），其中 3 个决策步（早/中/晚，步 10/22/34）+ 1 个傍晚社交步（步 44），其余为作息/移动空闲步。
- **居民**：25 位手写人设（`atria_personas.py`），每人种子记忆 = 人设 + 当日钩子 + 日常基线 + `currently` 字段（有锚条件在此注入碎片）。
- **社交协议**：傍晚社交步将 25 人随机打乱配成 12 对，`converse(a, b)` 让 a 基于**自己的全量记忆**生成一句转述，写入 b 的记忆（`"X 告诉我: …"`）。
- **记忆**：空闲事件不入流 + 近 8 条文本去重；每日产出 `dayNN.jsonl` 事件流与 `mem_dayNN.json` 记忆 checkpoint；断点续跑遇缺失 checkpoint 即中止（fail-closed），杜绝记忆空白重启。
- **LLM**：Atria-Dawn-Preview（OpenAI 兼容端点），令牌桶限流 40 RPM；`--seed` 控制随机性，`--neutral-social` 切除引导句。
- **零干预**：启动后运行期无人工介入；所有轮次共用同一引擎版本。

### 3.2 操纵变量

| 因素 | 取值 |
|---|---|
| 记忆锚点 | ON：10 位居民的 `currently` 字段含"邮局包裹错领"相关内容（失主/错领者/3 名目击者/经手人持事件碎片，另 4 人已听说）；OFF：人设中无任何包裹信息 |
| 引导句 | ON：每日社交 prompt 含"如果你清楚记得镇上那件'邮局包裹被错领'的事，就把它告诉 {对方}，讲出你记忆里最详细的情形"；OFF：中性社交 prompt |
| 传闻客体 | 包裹错领（默认）；银元（hint0g/multi 换刺激验证泛化） |
| 干预 | 无（默认）；第 7 天全镇注入辟谣公告（debunk） |

### 3.4 指标口径

- **知情（informed）**：某居民逐日记忆 checkpoint 中首次出现传闻标志词的日期。刻意不用事件 `say` 字段：引导句会污染台词（hint0g 中张石匠能照句反问"银元可是真的？"，但其记忆从未获得内容），记忆 checkpoint 才是可靠口径。
- **转述边（edge）**：从对话记忆 `"X 告诉我/回我说: …"` 提取的 src→dst 传播边；`first=1` 表示该边当日恰为 dst 的知情日（疑似首传）。
- **提及人数**：当日事件中 `say` 命中传闻标志词的独立居民数（活跃度口径，非知情口径）。
- **零注入传闻识别**：v3 各轮无预设客体，先对全镇逐日记忆做 n-gram 频次聚类找出发酵的故事线（s4"磨坊埋物"、s5"石匠失踪"），再以该故事词族回扫 checkpoint 计知情数；虚构性经行程记录核验（v3s5 中张石匠全程在镇公园一带，从未进山——失踪传闻为纯编造）。

## 4. 结果

### 4.1 RQ1 有锚信息的传播：近乎必然的全员饱和

十个有锚 run 全部达到 ≥23/25（v2 格 25/25/23/25/25，v4np 格 25/25/24/25/25），8/10 在 14 天内完全饱和（中位饱和日 v2=D13、v4np=D9）。

| 方向 | "抱着纸箱往镇东头走"（半具体） | 30 | 8 |
| 颜色 | "衣裳颜色偏浅，好像是灰色"（不确定） | 0 | 0 |

### 4.2 RQ2 零注入：自发编造传闻真实存在，但成败离散不可控

五个种子各自即兴虚构出**不同**的传闻：s1/s2"镇中新来一户人家"、s3"周家丫头出嫁"婚事、s4"老磨坊磨盘下埋东西"、s5"张石匠进山失踪"。最终知情 4 / 19 / 9 / 25 / 24 人，呈双峰分布：三格在 35 天内停在 ≤19，但 s4 在第 32 天完成全镇饱和、s5 停在 24/25。

值得注意的是 v3s4/s5 的传闻无任何事实基础——v3s5 中张石匠的行程记录显示他从未离开镇中心区域，"进山失踪"从头到尾是集体虚构。**自发叙事可以起飞，但何时起飞、起飞多快完全不可预测**：同是零注入，35 天里可以 4 人也可以 25 人。这与注入格的稳定性（14 天必然 ≥23）形成本质对照。

### 4.3 RQ3 引导句：传播非必要条件，但能在零锚下"播种"

- **广度**：关掉引导句，有锚传闻照样饱和（v4np 格 4/5 完全饱和；中位饱和日 D9 vs v2 格 D13，不减反快）。
- **深度**：碎片转述量降至约 1/4（164→44）：引导是扩音器，不是发动机。
- **播种**：零锚点 + 引导句时，包裹从未存在，全镇却集体编造并传遍完整包裹案——**五个种子全部 ≥23/25**（25/25/23/24/23），内容收敛于引导措辞并自发增殖归因句（"哪是错领，分明是手长"被多人转引）和追查行为（查底单、对签收、惊动巡检司）。

**传闻不靠事实传播，靠问题传播。** 这也意味着 v2 格的饱和中相当部分应归因于逐日 prompt 提示，而非纯粹涌现——提示本身就是叙事种子。

### 4.4 RQ4 刺激泛化：编造不依赖特定内容

把传闻客体换成"镇外山道挖出一坛银元"重跑同格条件：24/25 知情、72 条转述边，全镇照样编造出完整故事。唯一未达标的张石匠只有"都传遍了，就你闷在石场里"这类元指涉记忆：听见了传闻的存在，从未被告知内容（该案例也是"知情必须用记忆口径"的直接证据）。

### 4.5 RQ5 竞争与干预：两条边界条件（n=3 各自复现一致）

**双传闻并行（multi）**：引导句同时提包裹（有锚）与银元（零锚）。三种子结果一致：包裹 25 / 24 / 25，银元仅 2 / 9 / 5。单跑能传遍全镇的编造传闻（hint0g 24/25），在有锚对手面前几乎绝迹。**集体编造需要一个空的信息生态位。**

### 4.6 质性观察

以下三个案例均为原始事件流中可复核的涌现行为，非设定剧情：

- **反派弧线**：错领者孙有财呈现完整五阶段——侥幸（D1–7）→ 烦躁（D8–9）→ 掩盖（D9–12 销毁登记存根）→ 悔过还物（D13 趁夜放回门口）→ 观察确认（D14）；同期安镇在 D13–14 拿扳指线索逼值班员交出底单，销毁与追查形成时间赛跑。
- **传播失真链**：吴怀疑把赵医生的"没认出是谁"转述成"亲眼瞧见"，不确定性在转述中被丢弃；张石匠把多源碎片焊接成"李大姐亲眼瞧见 + 底单八天没翻出来"；王邮差虚构"查到周家""沈郎中说眼熟"（两人均无此言行）。
- **元指涉记忆**：hint0g 中唯一不知情的张石匠留下"都传遍了，就你闷在石场里"——居民可以"知道传闻存在"却"不知传闻内容"，两级知情必须分开度量。

### 4.7 组间统计

| 对比 | 分组 | 结果 | p（双侧 Fisher） |
|---|---|---|---|
| ≥23/25 达成率 | 注入格 2×2（15 轮） vs 零注入（5 轮） | 15/15 vs 2/5 | **0.0088** |
| 完全饱和（25/25）率 | 同上 | 10/15 vs 1/5 | 0.13 |
| ≥23/25 达成率 | 全部包裹向注入 run（22 轮，含 hint0g/multi-包裹/debunk） vs 零注入 | 22/22 vs 2/5 | **0.0034** |
| 双传闻格内 ≥24/25 | 有锚包裹 vs 零锚银元（各 3 轮） | 3/3 vs 0/3 | 0.10（n 小，仅参考） |

注入条件"传遍全镇"是统计上可靠的差异；而"14 天内完全饱和到 25/25"的差异方向一致但现有样本量下未达显著：两类结论应按强度区分陈述。累计转述边数的条件对比见 `figures/fig11_edge_growth.png`（注入/引导格 63–127 条 vs 零注入 3–159 条全谱），who-told-whom 邻接矩阵见 `figures/fig10b_adjacency.png`。

## 5. 讨论

五个结论可以被一条统一的机制线串起来：

1. **种子的有无决定结局的确定性**。只要镇子里存在传闻的初始痕迹——无论是真实碎片还是引导句本身的措辞——14 天内传遍全镇近乎必然（22/22 注入 run ≥23/25）。反之，没有任何种子的镇子能不能起飞纯属运气（4–25/25 双峰）。
2. **引导句是"伪种子"**。它不提供事实，却提供了叙事模板：居民顺着"邮局包裹被错领"这个问句集体编造出完整案件。这重新界定了有锚+有引导格的解释空间——其饱和部分归因于逐日 prompt 提示而非纯涌现。
3. **编造传闻需要空的信息生态位**。同一套编造机制，在有锚竞争者面前被挤出（multi 银元 2–9/25），在无竞争时却能饱和（hint0g 24/25、v3s4 25/25）。
4. **饱和是不可逆相变**。记忆一旦写入便无法擦除：辟谣公告只能压低表达活跃度（~13→~6/天），知情数始终钉在 25/25。

与经典扩散理论对照：知情曲线的 S 形与 SI 型流行病动力学同形，但本装置还多观测到 SIR 族无法表达的内容级现象——措辞确定性筛选、转述失真、集体虚构。对 LLM 智能体社会的含义同样直接：**prompt 里的每一句"提醒"都是潜在的叙事污染源**；合成社会实验中评估"涌现"时必须把 prompt 引导列为混杂变量；而"事后公告纠偏"在记忆不可逆的前提下收效有限。

## 6. 效度威胁

按内部/构念/结论/外部四类陈述：

- **内部效度**：有锚条件的初始碎片为作者设定，非零干预；"零注入"指零信息注入，非零人设注入；debunk 公告恰在第 7 天（饱和日）注入，测的是"饱和后辟谣"而非事前干预；multi 中两传闻锚点不对称（包裹有锚、银元零锚），回答的是"有锚 vs 零锚竞争"，不是一般性传闻竞争。
- **构念效度**：知情判定依赖标志词命中，对隐喻式转述可能漏报（下偏）；`say` 字段受 prompt 污染不可用（已弃用为知情口径）；零注入轮次的传闻词族由事后聚类确定，存在选择偏差风险（已用行程记录交叉核验虚构性）。
- **结论效度**：2×2 各格 n=5，可支持 Fisher 精确检验；multi/debunk 各 n=3、hint0g n=1，边界条件结论只按一致性趋势陈述，不做显著性声明；远程 LLM 同种子不逐位确定，复现的是趋势不是数字（实测底噪：v1/v2 同种子复跑 D1 事件 79 vs 78，数字应视为量级）。
- **外部效度**：单模型（Atria-Dawn-Preview）、单镇、单套人设、单文化语境、固定接触率（12 对/日）；结论是否随模型能力、镇子规模、接触结构迁移未知。
