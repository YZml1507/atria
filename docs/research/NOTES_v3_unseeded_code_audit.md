### atri­a_engine.py（327 行）★ 重磅发现
引擎本身也耦合剧情! converse() 函数的 prompt 写死:
  "如果你清楚记得镇上那件'邮局包裹被错领'的事, 就把它告诉 {b.name}"
→ 这是运行时注入, 不只是初始记忆注入!
→ v2 的传播数据 = 初始记忆(10人) + 每次 social step 的 prompt 提醒(全员) 的混合产物

## v2 传播数据归因（实测量化）
- 1109 事件, 含"包裹/纸箱" 657 条 = 59.2%
- 含碎片词(扳指/灰色/东头) 213 条 = 19.2%

→ 结论: v2 的传播几乎完全由注入驱动。converse prompt 的"如果记得就告诉"是主要放大器。
→ 164/30/0 的差异中, "初始记忆+prompt提醒"贡献远大于"智能体自发转述意愿"。

## 零注入的技术含义（待方案确定后执行）
要改的不只是 personas! 必须改引擎 converse():
  v2: "如果你清楚记得镇上那件'邮局包裹被错领'的事,就把它告诉X"
  v3: "如果你最近有什么值得一提的经历或见闻, 就讲给X听" (或纯自由闲聊)
否则删掉 currently 锚点也没用——引擎会在每次对话时主动提醒智能体聊(不存在的)包裹。
