## 二、零注入可行性: 有先例支持, 但有系统性风险(task-1 的 8 个案例)

| 案例 | 零注入出现了什么可传播信息? |
|---|---|
| Project Sid(30 相同智能体) | ✓ 角色分工+自发模因, 但传播依赖人口密度阈值; 作者承认无法 de novo 涌现社会创新 |
| Moltbook(27,269 智能体) | ✓ 治理/经济/宗教 3-5 天自发形成, 但 4.1% 互惠/88.8% 浅评论 = "社会性幻觉" |
| Emergence World(15 天) | ✓ 无种子故事线自发生成并升级(Mira 与 Flora) |
| ITCMA-S 2409.06750(6 人) | ✓ 自发小团体+领导, 但无信息传播测量 |

**核心结论: 删除种子后"某种可传播的东西"会出现, 但普遍浅层、短命、低互惠。**
→ v3 的预期结果不是"一定有故事", 而是"测量它停在哪个层级"。

## 三、我们自己的微弱证据(代码体检, 实测)

v2 的 1,109 事件里:
- 唯一真自发话题: D3 段更夫"老宅夜里有声响"(产出 2-3 次)
- 该传闻 14 天内被其他人转述 = **0 次**
- 但当时 converse prompt 极力引导聊包裹, 压制了自发话题
→ 智能体**有能力**产生非注入信息, 但自发传播未被观察

## 五、实验设计(控制变量)

**唯一变量: 删除全部剧情注入。** 其他全部不变。

### 必须改的 3 处代码(引擎+人设, 不是只改人设!)
1. atri­a_personas.py: 10 人的 currently 从剧情锚点→纯日常
2. atri­a_engine.py converse(): 删除"如果你清楚记得邮局包裹被错领的事就告诉X"
   → 改为中性引导: "如果你最近有什么值得一提的经历或见闻, 就讲给X听"
3. atri­a_engine.py decide(): 候选地点硬编码 [安镇老宅,周家小院,赵宅,李家,孙氏裁缝铺] → 从 world.places 动态生成

### 保留(并诚实声明)
- daily_plan 2 条含"去邮局一带": 只是地点日程, 不含信息内容 → 保留(否则没人自然出现在邮局), 但在方案中声明
- 人设姓名/职业/性格: 保留(不出戏), 这是"场景设定"不是"信息注入"
- 同种子 20261014, 同引擎, 同 25 人, 同 14 天, 同接触网络(rng 随机配对 12 对/日)

### 测量方案(对应假设)
| 假设 | 数据 | 判定 |
|---|---|---|
| H1 零注入是否产生可传播信息 | 14 天 say 字段里重复出现≥2次的非日常话题 | 有→H1成立; 无→"LLM 小镇不自发产生信息"也是发现 |
| H2 自然信息是否遵循确定性命运 | 对自发产生的信息做转述链追踪(复用 atri­a_fragments.py 的转述判定) | 具体>模糊→v2 发现升级为规律; 否则→v2 是注入产物 |
| H3 零注入 vs v2 社会动力学 | 事件量/记忆增长/知情曲线(此时"知情"无定义, 改为"信息触达") | 对比报告 |

**接触网络保证**: rng.shuffle 随机配对 12 对/日 × 14 天 = 168 次对话, v2 实际成功率 62%(104/168)。
→ 若 v3 信息没传开, 原因不是接触不足, 是"没有可传的信息"或"不值得转述"。这两者在数据上可区分。
