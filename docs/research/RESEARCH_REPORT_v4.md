## 一、最重要的事：512K 是真的，子代理想错了

子智能体（task-3）断言「Atria-Dawn 只有 256K，喊 512K 会信誉破产」。

**本机实测推翻该断言：**

| 证据 | 结果 |
|---|---|
| API 实测 | 280,062 token 单次调用**成功**（19-47 秒），服务端接受 |
| 官方给用户的邮件 | 「新模型支持 **512K 上下文**、64K 输出」 |
| 本机 Hermes config | `context_length: 512000` |

子智能体查的是 HuggingFace 上**旧版 Preview 的模型卡**（写 256K），但参赛用的是**正式版**（Atria-Dawn-Preview 模型名自动路由到新模型）。**它查的是上一代。**

**结论：按 512K 执行，不听子智能体的。**

### 但它的后半句有道理

「长上下文≠记得牢」这个质疑本身成立：NoLiMa (ICML 2025) 测得 GPT-4o 从短上下文 99.3% 掉到 32K 时 69.7%；RULER 测 17 个宣称 32K+ 的模型只有约一半能有效使用 32K；Liu et al.「Lost in the Middle」U 形曲线。

**所以核心叙事不能只喊"窗口大"，必须实测"记得住"。** 这正是下一步压测的目的。

### 新技术信息：Content 返回 None = reasoning 模式

长上下文调用返回 `content=None`，答案在 reasoning 流里。这对沙盒是利好：角色"想了再说话"天然契合。工程上直接读 reasoning 输出。

## 二、学术地基：Smallville 论文精读 (arXiv:2304.03442, UIST'23)

### 架构三件套（§4）

| 机制 | 细节 |
|---|---|
| **记忆流 §4.1** | 每条记忆 = 描述 + 创建时间戳 + 最近访问时间戳。检索 = recency（指数衰减 decay=0.995）+ importance（LLM 打 1-10 分）+ relevance（embedding 余弦相似度），三项 min-max 归一化后权重全 1，top-k 装入上下文 |
| **反思 §4.2** | 触发：最近事件重要性累计超阈值 150（每天约 2-3 次）。流程：取最近 100 条 → LLM 提 3 个高阶问题 → 检索 → 提取 5 条洞察并引用证据编号（"insight because of 1,5,3"）。**反思可嵌套成反思树**，叶=原始观察，越往上越抽象 |
| **规划 §4.3** | plan = (地点, 开始时间, 持续时长)。自顶向下递归分解：日计划 5-8 大块 → 小时块 → 5-15 分钟动作。§4.3.1 反应与重规划：每步判断是否中断计划（家庭成员回家会去打招呼，旁人安静坐着不响应） |

**25 个人设 §3.1**：每 agent = 一段自然语言描述（职业+人际关系+性格），每个分句作为一条种子记忆注入。例：John Lin 的描述含妻子 Mei Lin、儿子 Eddy、邻居 Sam/Jennifer Moore 等 13 个分句 → 13 条种子记忆。

**地图 §3.2**：Phaser 前端 sprite 2D 沙盒（类 The Sims），场景含 cafe/bar/park/school/dorm/houses/stores。1 步 = 游戏内 10 秒。

### 涌现案例清单

**设计者预期内（4 类）：**

| 案例 | 数据 |
|---|---|
| 情人节派对自组织 §3.4.3 | 种子仅 2 条（Isabella 办派对 + Maria 暗恋 Klaus）。25 人中 13 人(52%)得知，12 人被邀，5 人出席；7 名未到者中 3 人给出合理理由 |
| 市长候选人信息扩散 §3.4.1 | 知晓 Sam 竞选者从 4%(1/25) 扩散到 32%(8/25)，全部可在记忆流中验证，无人凭空捏造 |
| 新人际关系与跨日记忆 §3.4.2 | 网络密度 0.167 → 0.74；453 条"认识谁"应答中仅 6 条(1.3%)幻觉 |
| 反思改变决策 §4.2 | 有反思后 Klaus 从选互动最频繁的 Wolfgang 改选 Maria（共享研究热情） |

**意外/失败类（3 类，对"诚实演示"更有叙事价值）：**

| 案例 | 内容 |
|---|---|
| 社会规范违例 | 多名 agent 中午去酒吧吃饭，小镇"自发形成午后饮酒习惯"（作者原意酒吧仅晚间场所） |
| 过度顺从与合作污染 | Isabella 几乎全盘接受他人派建议，兴趣逐渐趋同；Yuriko 把邻居 Adam Smith 说成"《国富论》作者" |
| 记忆修饰 | 非完全捏造，而是 embellishment——Isabella 给 Sam 的竞选凭空加上"明天要宣布"的细节 |

### 消融实验（§6，100 名 Prolific 评估者）

全架构 TrueSkill μ=29.89 > 无反思 26.88 > 无反思无规划 25.64 > 人类众包 22.95 > 全砍 21.21。
相对 prompt-only SOTA 效应量 **d=8.16**，Kruskal-Wallis H(4)=150.29, p<0.001。

**"架构 > 模型"是论文最硬的结论——直接支持用 Atria-Dawn 做基座。**

## 五、视觉方案（task-3 交付）

### 三个标杆的渲染路线

| 项目 | 技术栈 | 视觉决策 |
|---|---|---|
| Smallville | Phaser 3 + Tiled 像素瓦片 + Django | 低饱和像素底图 + 高对比角色精灵；头顶气泡 emoji + 动作文本标注。**短板：角色精灵外观全部相同** |
| Project Sid | Minecraft 游戏内渲染 | 视觉核心不是前端而是**分析图表矩阵**：时间序列/热力图/洛伦兹曲线/力导向网络，每面板对应一个涌现维度 |
| Emergence World | React Three Fiber 3D + FastAPI + WebSocket | **Replay 回放系统**，同一世界仅换底层模型，用"分叉命运"对照展示 |

### 我们的技术栈（无 GPU 约束下）

1. **主渲染**：manim Community v0.21.0（Cairo 后端 2.2x 提速 + 并行编码）。关键技巧：**数据密集图层预烘焙为 PNG，作为 ImageMobject 叠加**，只让少量关键元素做向量动画
2. **数据密集图层**：Pillow 直接绘制 1920×1080 底图/轨迹/热力图（比 manim 快 1-2 个数量级）
3. **图表层**：时间序列用 uPlot 风格 Canvas 画法（3600 点 60fps 仅 10% CPU）
4. **合成**：ffmpeg `-f image2pipe -crf 18 -bf 0` 合成 1080p60，edge-tts 旁白混入

|---|---|
| 底色 Near-Black | `#0B0E14` |
| 面板 Panel-Charcoal | `#151A23` |
| 主文字 | `#E8EDF4` |
| 次文字 | `#8A94A6` |

| 涌现色 Emergence-Amber | `#FFB347`（交易、异常、警告） |

智能体三色编码状态：`#41EAD4`（活跃交易）/ `#8A94A6`（日常移动）/ `#FFB347`（异常冲突）。
**亮像素占比 < 15%，强调色 < 3% 面积。**

### 视觉规律

1. 暗底 + 单一高饱和强调色（Awwwards SOTD 共性）
2. **涌现感 = 对照与分叉**（Emergence World 的核心策略，不是画得多炫）
3. 微观-宏观呼吸：3 秒微观特写 → 5 秒宏观面板 → 地图全景
4. 运动分层：背景慢（30s 周期）→ 中景稳（匀速移动）→ 前景快（0.5s 闪现）
5. 克制：数据层不要花哨动效，动效预算全留给涌现事件本身
6. 像素/扁平而非拟真——自带"沙盒模拟"类型暗示

## 六、风险与差异化

### 风险清单

| 风险 | 概率 | 缓解 |
|---|---|---|
| **512K 被质疑**（子代提出，已证伪其事实基础） | 低 | 官方邮件+API 实测可证；下一步压测"记得住" |
| **涌现不出来** | 高（~70%） | 预置高冲突种子（秘密/债务/三角关系）；导演层监控张力；准备 fallback 回放；蒙特卡洛跑 ≥20 次取最稳路径。**绝不写死剧情**（PIMMUR: 50.6% 的 prompt 预决定结果） |
| **评委觉得"不就是聊天机器人互相说话"** | 很高（~85%） | ① 数据面板压过对话框：主视觉是记忆一致性仪表盘（矛盾率/OOC 率/承诺履约率）；② agent 用工具真实改变世界状态（Atria 工具调用第一：BFCL v4 77.0 / AutomationBench 53.8）；③ 视觉克制 + 微观宏观呼吸 |
| **Smallville 衍生品同质化** | 高（~80%） | 差异化锚死在"512K 全量记忆 + 检索第一"这个组合上——竞品全是 RAG+向量库+压缩架构，fork 不走这一点。**叙事上明确对标：我们是 Smallville 的对照实验，不是第 994 个 fork** |
| **与官方撞车** | 中（~50%） | 官方占的是概念层（World Proxy position paper）与 RL 训练设施（Intern-S2），非消费级可视化。化撞车为站队：引用这条脉络，定位为"官方路线在面向公众可视化形态上的补完" |
| **纯文本模型，不能看地图** | 高（~75%）工程摩擦 | 空间逻辑全部放引擎层（坐标/寻路确定性代码），模型只收发文本世界状态——本就是 Smallville 的做法 |

### 差异化叙事（修正后）

核心叙事 = **「可证伪的记忆压测」**，不是「好看的小镇」：

1. **破**——同台对照：同一个镇、同样角色、同样时长，A 路 32K 模型+RAG 压缩流，B 路 Atria 512K 全量记忆。现场投屏显示实时指标：事实矛盾率、人设漂移度（OOC 率）、承诺履约率、关系网络一致性
2. **立**——agent 不只说话，用工具真实改变世界状态（发帖/记账/下单/写文件），命中官方 Creation 维度 games 条款
3. **收**——结尾一句可验证断言：「72 小时连续运行，矛盾率 < X%，A/B 差距 Y 倍」

**一句话：不要卖小镇，卖「长时程 agent 记忆一致性的公开处刑现场」。**
