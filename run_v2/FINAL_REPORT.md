## 2. 涌现结果

### 2.1 三碎片命运分化

三位目击者各自持有一枚信息碎片，关于同一个错领事件：

| 碎片 | 传播记忆条数 | 传到 |
|---|---|---|
| 李大姐-扳指（戴旧扳指） | **164 条**（本人自记另 6 条，不计） | 周老师、郑大妈、韩屠户、何书生、朱寡妇、张石匠… |
| 赵医生-方向（往镇东头走） | **30 条**（本人自记另 3 条，不计） | 吴怀疑 → 王邮差 → 沈郎中、许货郎 |
| 周老师-颜色（衣裳颜色偏浅、好像是灰色） | **0 条** | **无人** |

**信息保真度分化涌现了。** 同样是目击者碎片，传播力差 5.5 倍（164 vs 30，均排除持有者自记）：

- **扳指碎片最具体、最可验证**（"张石匠说那扳指值不少钱呢"）→ 传播最广
- **方向碎片中等**，且在转述中固化（赵医生 D6："错领一事我不敢断言"；她保留不确定性，但转述者会丢掉它）
- **颜色碎片措辞不确定**（"没看清脸，只记得那人穿的衣裳颜色偏浅"）→ **LLM 转述时主动放弃了不确定信息**，0 次传播

**跨轮复现**：v1 与 v2 同种子运行，碎片绝对数差异很大（36 vs 164），但秩序完全一致：颜色两轮皆 0，扳指两轮皆最广。**不确定性信息在传播链上被自然淘汰**，这是一个跨运行稳定的现象。

## 5. 数据与结论的局限

1. **记忆密度 40 条/人仍无法在正式跑验证 512K**：512K 能力由 P1v5 独立支撑（6,304 条 / 138,454 token，全量 3/3 vs RAG 1/3）。
2. **无人指认错领者**：不是记忆截断（孙有财仅 40 条记忆），而是**传播网络绕开了他**：他每天守在五金店/邮局一带，而八卦集中在广场与中街。
3. **单种子**：v1/v2 同为 seed 20261014，对照测的是机器噪声，不是种子稳健性。后者需换不同种子（未做）。
4. **颜色碎片 0 传播是观察，不是定律**：v1/v2 两轮一致，但样本为 2，不足以称规律。
5. **数字携带机器噪声**：同种子 D1 79 vs 78 已证实；本文所有具体数字应视为量级，非精确值。
